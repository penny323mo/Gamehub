### Elden Ring II：死一次返返第一波，而冇測試去得到 boss 場 (ADR-182)

- ADR-170 開住、擱咗兩輪：`restart()` 無條件 `encounterStage = 0`。由頭到尾量過——清咗第一波、死喺第二
  波、撳 R，**返返去 wave-1**。你行完嗰段要再行一次，而個場明明有賜福做 checkpoint。而家跟 soulslike
  慣例：**敵人重置、世界進度唔重置**（boss 回滿血、你死嗰波原封不動再嚟、清咗嘅唔翻生、霧門跟返你到咗邊）。
- **佢擱得三輪嘅原因係冇測試去得到 boss 場**：清三波雜兵喺一秒三幀嘅環境要幾分鐘，所以「死喺 boss 手上
  再重開」係一條從來冇行過嘅路（同 ADR-179 個 `locked` 一樣個形）。`__ER2.推關()` 解決咗：佢**冇重寫
  任何嘢**，叫嘅係遊戲自己嗰兩個轉換函數，同 `zoomBy` 一樣。
- 佢即刻捉到一個**我啱啱先寫出嚟**嘅缺陷：重開set `gateFade = 1`，而每幀嘅淡出段 `if (bossActive &&
  gateFade > 0)` 會將 `visible` 覆蓋返 true——即係喺 boss 場中間**淡出一道畫得出、但攔唔到你**嘅霧門。
  條 gate 問嘅嘢值得留：**畫幾多道，就要攔幾多道。**
- **同 ADR-181 一模一樣個 build 坑，又中一次**：突變有 type error、`npm run build` 中止、舊 `dist` 留
  喺度，探針讀到健康數字。**突變之後啲數唔郁，第一件事係查個 build 有冇真係出過新 bundle。**
- **一個 flake 由結構上剷走**：入場嗰三步喺六個地方各抄一份 Playwright `click()`，而佢會等一個永遠唔嚟
  嘅 navigation。套件開到第八版嗰陣第六版開始 timeout——手機版塊一早記低咗呢件事同佢個 DOM-click 解法，
  但只喺一個地方。而家得一個 `入場()`。
- 版位 gate **72 → 76**。

### 上一輪：個打擊特效唔知自己代表緊一下打擊 (ADR-181)

- **全場得一組碎屑**：`burst()` 每次覆蓋同一個 `THREE.Points`，0.55 秒未散完又有第二下打擊，頭嗰蓬就
  **成蓬瞬移**去新位置。實測真打鬥入面 **七次有兩次（29%）**被搶。而家一個五個嘅池，實測同時最多用兩個。
- **噴濺同打擊方向完全冇關**：水平等向亂數，垂直係 `rand × 4.2`——**永遠 ≥ 0**，42 粒有 39–42 粒向上。
  無論邊個方向斬落去都係同一個噴泉。而家係一個繞住打擊方向嘅錐；集中度由 **0.03–0.11**（噪音）升到
  **0.75–0.93**。**碎屑重力寫住 5**（半空慢動作）——由積分度返，**5.0 → 9.80**。
- **一個要記低嘅坑**：第一次突變跑出嚟 **72/72 全綠**。個突變有 type error、`npm run build` 中止咗，而
  **舊 `dist` 仲喺度**——套件派嘅就係 `dist`，於是佢開開心心咁測咗個冇突變嘅 bundle。**build 失敗會留低
  一個讀落似成功嘅舊產物。** 改到編譯得之後三條全部紅，而且重現到原本個數。
- 鏡頭震仲係固定 0.24（傷害 13 到 22 都一樣）：source 度睇得到，但我冇量過佢係缺陷，冇郁，記低。
  版位 gate **69 → 72**。
