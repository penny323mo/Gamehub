  **跟住變矮**（兩個數一齊縮，角色塞爆成幅畫），而家逼近就升高俯視。
- **冇縮放**：深淵之橋一早有 `view.zoomBy`（夾 0.7–1.7、滾輪 + 雙指、6px 死區）。ER2 而家同一條規則、
  同一組上下限、同一個死區。
- **控桿太左**：釘死喺版面，兩個打橫尺寸中心喺畫面 **8.3% / 10.5%**、離邊 20px。深淵之橋嘅答案係搖桿
  **冇位置**：撳左邊 55% 任何一點佢就喺你手指下面出。ER2 而家一樣，52px 行程。
- **改完即刻整出兩個新缺陷，靠成套重跑捉返**：搖桿抽出 flex flow 之後 `space-between` 淨返一個仔，三
  粒動作掣被推去**左邊**跌入搖桿區（撳攻擊會開咗搖桿）；`setPointerCapture` 冇 active pointer 會掟錯、
  打斷成個 handler（深淵之橋一早用 `try` 包住）。條新 gate 自己都錯過一次：手機 CSS 收喺
  `@media (pointer: coarse)` 入面而套件個 page 冇 touch，佢報「搖桿出咗喺 (0, 0)」——而家喺 `hasTouch`
  context 度行。
