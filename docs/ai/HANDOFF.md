### Elden Ring II：我加嘅藥瓶飲唔到 (ADR-188)

- ADR-187 加咗三支藥。跟住我量佢用唔用得着：兩局 bot **想拉開 21 次、成功 0 次、一支都冇飲過**。
- 成因係兩個從來冇比較過嘅數：玩家行 **4.4**（wizard 4.2），雜兵 **[3.6, 4.1, 4.4]**——**第三波同你一模
  一樣快、仲快過 wizard**。行路每秒賺 0.3 米，開 7 米要 23 秒；唯一拉得開嘅係衝刺，而佢食 13/秒**兼且
  封鎖 28/秒回氣**：**拉開嘅工具，食緊你拉開想回復嗰樣嘢**。而家 73/77/84%，每秒賺 1.2／1.0／0.7 米，
  實測由 1.8 米行到 **5.9–6.6 米**。條 gate 比較**遊戲自己兩個數**，唔係我拍個門檻（舊值第三波 **0.0**）。
- **我支尺犯咗同隻遊戲一樣嘅毛病，而我一輪之前先寫低過**：個 bot 用真實毫秒落指令，1.2 秒衝刺撤退喺
  三四幀嘅環境入面 ＝ **0.2 秒遊戲時間**，只行到 0.7 米。同 ADR-187 嗰四條 gate 一模一樣個窿——**腳本
  用真實秒寫，而佢驅動嘅嘢行郁動時間**。bot 而家等郁動秒。
- **仲係未證實**：bot 去到第二波就死。呢兩輪每個結論都窄而且各自量過（血預算蓋得住條路、拉開窗口而家
  存在），但真人通唔通到未有證據——而改個 bot 改到佢話「得」就變成量緊個 bot。版位 gate **89 → 90**。

### 上一輪：條路需要嘅血多過隻遊戲畀你嘅 (ADR-187)
