### Elden Ring II：貼身打唔中人 (ADR-189)

- 逐下斬記低距離、角度、中定空，個型即刻出嚟：**4.2 米中、2.4 米中，但 1.6／1.8／1.8 米全部空**——
  **近距離斬空、遠距離先中**。成因係前搖嗰 0.27 秒踏前推你向前約 0.86 米，而雜兵同時埋身 0.86 米：
  **你衝過咗頭，佢跌咗去你身後**，而落點判定要求佢喺你前面。玩家實際輸出 **0.4 dps**（設計 11.9）。
  踏前而家停喺接觸面（距離仍然由招式決定）——同一段量度：**打出傷害 30 → 128**。
- 記埋角度就見到第二條邊：前搖只夠轉 **70°**，而空嗰啲全部係 148°／156°／180°，115° 以內全中——即係
  **遊戲揀咗一個你轉唔切嘅目標，再收你 17 體力**。**我試過修，結果更差**：「轉唔切就唔揀佢」整咗個死鎖
  （背住敵人 → 冇目標 → 唔轉身 → 永遠背住），每一斬 180°、傷害由 128 跌返 **17**。剷咗：**轉得慢好過唔轉**。
- **第三個缺陷喺加藥瓶 gate 嗰陣浮咗出嚟：互動輸入畀食咗。** `queuedInteract` 每幀無條件清零，而飲藥
  要求 `now >= knockbackUntil`——**你啱好喺捱打嗰一幀撳 E，個輸入就靜靜哋冇咗**，而你淨係打緊交先想飲。
  條 gate 讀得好白：撳咗 E，血 50 → 40、藥 3 → 3。而家緩衝 0.45 秒，讀返 50 → 100。
- **同一個「真實秒 vs 郁動時間」嘅窿，今個 session 第三次**：重力 gate 撳完攻擊等 250 毫秒，而落點喺
  0.27 郁動秒（≈1.1 真實秒）之後——兩次抽樣都落喺落點之前，永遠讀 `null`。
- **通關仍然未證實**：修完之後 bot 命中率 2/5 → **7/7**，第一波剩 90 血過關，第二波用晒三支藥、殺一隻、
  死。比之前每一輪都好，但唔係通關。再調落去就變成量緊個政策。版位 gate **90 → 91**。
