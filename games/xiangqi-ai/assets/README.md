# Xiangqi environment asset

`studio_small_09_1k.hdr` is the Poly Haven **Studio Small 09** HDRI used as the
optional board environment light.

- Source: https://polyhaven.com/a/studio_small_09
- License: CC0 1.0 Universal (public-domain dedication)
- SHA-1: `47c871ff1527746ebefdce6cf2abea4d1b62c0`

The file is bundled so GitHub Pages and offline/blocked-network sessions do not
depend on a third-party request. The renderer still keeps its local lights as a
fallback if the bundled file cannot be decoded.
